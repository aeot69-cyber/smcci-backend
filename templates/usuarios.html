⚙️ Usuarios y Permisos Gestión de accesos

❓ Ayuda
  • Crear usuario: asigna usuario, contraseña y rol. La contraseña debe tener: 8+ caracteres, mayúscula, minúscula, número y signo. El nuevo usuario deberá cambiar su contraseña al primer ingreso.
  • Rol SUPERADMIN: acceso total a todo el sistema incluyendo gestión de usuarios.
  • Rol ADMIN: puede crear/editar usuarios pero NO asignar rol SUPERADMIN.
  • Rol CONSULTA: solo puede consultar y exportar. No modifica datos.
  • Vincular a líder: relaciona el usuario con un líder del sistema para identificación interna.
  • Permisos: marca las casillas para definir qué puede hacer cada rol en cada módulo del sistema.
  • 🔒 Bloquear: desactiva el usuario sin eliminarlo. P/reactivar con 🔓.
  • Recuperar contraseña: desde el login se envía una clave temporal al correo del líder vinculado al usuario. Si no tiene líder o correo, contactar al administrador.

❓ Ayuda de Permisos
  • Ver (Leer): puede acceder a la página del módulo y ver los datos.
  • Crear: puede agregar registros nuevos (ej: nuevo hermano, nuevo líder).
  • Editar: puede modificar registros existentes.
  • Eliminar: puede borrar registros permanentemente.
  • Exportar: puede descargar Excel y PDF del módulo.
  • Los cambios se aplican inmediatamente al presionar "Guardar Permisos".
  • SUPERADMIN siempre tiene todos los permisos marcados.
